Implementation of various mathematical models (differential equation models, complex systems, etc.).

The structure of the code (as well as the models themselves) are heavily inspired by Introduction to the Modeling and Analysis of Complex Systems by Hiroki Sayama (ISBN 9781942341093)

The pycxsimulator.py file used can be found at https://github.com/hsayama/PyCX/blob/master/pycxsimulator.py
